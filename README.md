# 1.8-54-MHz-controller-and-tuner
Open-source controller project for an HF power amplifier (1.8–54 MHz) and a tuner controller.
Открытый проект создания контроллера управления усилителем мощности от 500 до 2500ватт.
Может присоединиться любой желающий.
